# No Prime Popup for Amazon

A userscript that attempts to hide the Amazon Prime signup popup on every Amazon storefront (.com, .co.uk, .de, .fr, .co.jp, etc.)

## Install

1. Install a userscript manager: [Tampermonkey](https://www.tampermonkey.net/), [Violentmonkey](https://violentmonkey.github.io/) or [Greasemonkey](https://www.greasespot.net/).
2. Open [no-prime-popup.user.js](https://raw.githubusercontent.com/wackget/NoPrimePopupForAmazon/main/no-prime-popup.user.js) and confirm the install.
